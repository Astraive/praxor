Q1 adds one engine-owned `query::compile` entry point for a read-only single-collection `SELECT` or `EXPLAIN SELECT`. The accepted subset has `*` or named projection, scalar comparisons, `AND`/`OR`/`NOT` and parentheses, typed `$1`/`:name`/`@name` bindings, and specified SQL three-valued null/absence rules. It checks input, token, nesting and positional parameter bounds. A detached, process-local `QueryCatalogView` binds into a private-field `BoundSelect` or a distinct `ExplainV1` without literal/parameter values or row data and rejects stale or foreign owner/revision. Explain still exposes collection and field names, predicate/operator shape, catalog revision and required capability. `execute_in_memory` validates every referenced field on every caller-supplied immutable `document::Record`, retaining document IDs, input order and projection order. It does not read live storage.

The compiler returns typed refusals for unsupported forms including joins, functions, grouping/aggregation, ordering, limit/offset, CTE/window, history/`AS OF`, `DISTINCT`, aliases, `BETWEEN`/`IN`/`LIKE`, set operations, `WATCH`, PQL `FIND`, mutation/DDL and specialized search/vector/graph clauses; this list is illustrative, not exhaustive. Programmatic legacy `LogicalPlan` input is classified then always refused because it lacks projection/literal provenance. Existing parser and serde forms remain available. Separately, the legacy planner and executor now refuse only the previously ignored `AsOf` and `GroupBy` semantics before `RecordProvider` access; they do not become a validated Q1 route.

`docs/query-readiness.md` already contains the committed Q1 clarification (`0946b30489095ddd77caf12c9259bd119ebcc6ad`): its matrix describes the experimental legacy parser/planner/executor, while the bounded typed compiler is a separate path. No live row/catalog consistency, persisted catalog generation, query index, durable history, product REST/GraphQL/PQL route, full SQL or performance guarantee follows. Q2/#62 owns a fallible retained storage view, Q3/#63 owns persisted catalog mutation, and later routing must adopt their reviewed authority.
