# Contributing to praxor

Read [README.md](README.md) for this repository's current boundary, [GIT.md](GIT.md) for the full issue/specification/commit/PR/Project workflow and [development](docs/development.md) for checks. [AGENTS.md](AGENTS.md) is the concise agent entry point.

Start from an existing detailed issue or use a repository issue form. Keep native parent, blockers, milestone and [Project #2](https://github.com/orgs/Astraive/projects/2) fields synchronized. Use actual issue/spec hyperlinks, preserve existing progress and verify historical reports before proposing fixes.

The [foundation issue](https://github.com/Astraive/praxor/issues/104) tracks this contribution setup. One-time backlog publication scripts and their API state stay outside the repository.
